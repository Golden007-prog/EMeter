# Código de conducta

## Compromiso

Este proyecto busca que cualquier persona pueda verificar lo que le cobran. Participar aquí
implica tratar a las demás con respeto, sin importar su nivel técnico, su origen, su identidad
o su conocimiento del dominio.

## Qué se espera

- Crítica técnica concreta sobre el código y las decisiones, nunca sobre las personas.
- Suposiciones explícitas: si crees que un cálculo está mal, muestra el cálculo.
- Paciencia con quien recién empieza y con quien no conoce el negocio.
- Reconocer el trabajo ajeno y citar las fuentes cuando corresponda.

## Qué no se acepta

- Insultos, acoso, discriminación o comentarios sexualizados.
- Publicar datos personales de terceros, boletas reales o direcciones de suministro.
- Presentar como resuelto un problema de cobro sin evidencia reproducible.
- Usar los issues para promocionar servicios o atacar a empresas concretas.

## Alcance

Aplica a issues, pull requests, discusiones, wiki y cualquier espacio del proyecto.

## Aplicación

Quien mantiene el repositorio puede editar o eliminar contribuciones que incumplan esta norma,
y bloquear temporal o permanentemente a quien la incumpla. Para reportar una conducta, usa el
reporte privado del repositorio o escribe a quien mantiene el proyecto.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/),
versión 2.1, adaptado al tamaño y propósito de este proyecto.
