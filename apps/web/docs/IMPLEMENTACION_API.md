# Implementación de las funcionalidades de la API

Revisión: 17 de octubre de 2026. **45/45 operaciones implementadas y ejercitadas con respuesta exitosa desde el navegador**, con datos sintéticos y backend real. El [plan](PLAN_IMPLEMENTACION_COMPLETA_API.md) conserva el alcance y la situación inicial. El [contrato capturado](openapi/v1.json) corresponde al OpenAPI consultado en `http://localhost:8080/openapi/v1.json`.

## Resultado funcional

- E0: transporte JSON exacto, multipart, binarios, respuestas 204 y ProblemDetails; decimales y fechas de Santiago; información de versión.
- E1–E2: cinco catálogos con búsqueda, relaciones, paginación, detalles, altas y edición; principal de condominio; contexto de período en URL y cambios de estado.
- E3: captura con idempotencia, históricos, revisión, corrección con control de versión, rechazo/reincorporación, anulación e historial paginado.
- E4: originales, bandeja persistente OCR, seguimiento, revisión humana, confirmación, retry de Failed y asociación de evidencias.
- E5–E6: cinco reportes con unidades/orígenes y datos incompletos; panel operativo y cierre irreversible.
- E7: harness aislado y stack completo desechable, trazabilidad por operación y documentación de ejecución.

## Recuperación y límites

Se verificaron recálculo al intercalar históricos, conflictos reales de versión con borrador conservado, respuesta perdida en una captura (mismo requestId/cuerpo, una sola lectura), rechazo/reincorporación, anulación, auditoría paginada, cierre y rechazo atómico de recálculo histórico indirecto, conciliación completa/incompleta y separación por unidad/origen. El límite `9999999999999999.99` se envió y recuperó sin redondeo.

OCR se ejecutó sobre PDF, PNG y JPEG sintéticos. Se descargó el original y se compararon sus bytes; se repitieron confirmación y asociación sin duplicación. Se provocó Failed deteniendo únicamente el OCR de pruebas y se recuperó mediante retry. Se reiniciaron API, Worker, PostgreSQL, MinIO y OCR del proyecto desechable y se recuperaron lectura, trabajo y archivo. Esto verifica integración y persistencia, sin prometer exactitud universal sobre boletas reales.

Los errores de validación y conflicto de propiedades y las respuestas 413/500 de upload incluyen intercepciones controladas; el límite local de 20 MiB impide enviar un archivo excesivo; la concurrencia, el cierre, el fallo/retry OCR y la persistencia usan respuestas y servicios reales. La suite aislada no certifica almacenamiento durable. Las pruebas de escritorio, móvil y teclado cubren recorridos concretos; no constituyen una auditoría exhaustiva de accesibilidad ni certificación de otros navegadores.

No se cambió el código del backend ni se ejecutaron escrituras contra la API de trabajo en 8080 durante esta implementación. El servidor de desarrollo en 5173 puede continuar activo mientras se prueban puertos independientes. El rediseño visual queda para la etapa posterior indicada por el usuario.
